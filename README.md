# Maker's Pet Vac ROS2 robot

A mock vacuum cleaner robot compatible with [Kaia.ai](https://kaia.ai) software [platform](https://github.com/kaiaai/). 3D print, build, run and mod your own home pet robot! Please learn more at [Maker's Pet](https://makerspet.com), [REMAKE.AI](https://remake.ai) and join our [FB group](https://www.facebook.com/groups/243730868651472/).

Questions? Please visit the [Support Forum](https://github.com/makerspet/support/discussions/)!

## Features
- room mapping using a 360-degree laser distance sensor (ROS2-based).
- autonomous self-driving (ROS2-based).
- code your character, skills (work in progress)
- 3D-printable, 340mm round base
- Arduino ESP32 micro-controller
- LDROBOT LD14P LiDAR sensor
